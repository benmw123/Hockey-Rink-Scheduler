# Hockey-Rink-Scheduler
Used for scheduling sports games and events at sporting facilities. Takes several different teams, tournaments, public skates, pro-time, drop in, and stick &amp; Puck time and generates optimal schedules

USER WILL TAKE THE FOLLOWING:

RESTRAINTS SUCH AS HOLIDAYS AND HOURS
LEAGUES
  - Playing days
  - ideal playing time (for instance, you wouldn't want a kids league game at 10pm, nor would you want a adult league game at 8am)
      - Teams
      - special rules: no back to back; required off days, etc.
PUBLIC SKATE
  - Ideal skate times and days
  - minimum amount of skates wanted per week/day

etc

There may be other events, such as tournaments, training sessions, figure skating only, etc, etc.
